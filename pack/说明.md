# r2modman 简体中文汉化包

适用于 **r2modman 3.2.20**（Windows）。安装后界面直接显示简体中文，并可在语言菜单里
随时切回 English / Français。

> 本汉化包只修改 `r2modman\resources\app.asar` 这一个文件，改前会把原文件原地改名为
> 备份，**还原时只是把名字改回来**，不重新下载、不重装。

---

## 一、快速开始

### 1. 关闭 r2modman

**必须先完全退出 r2modman**（含右下角托盘图标），否则脚本会拒绝执行。

> ⚠️ r2modman 会在退出时自动安装已下载的更新。如果它刚更新过，`app.asar` 会被换掉，
> 装完汉化后请勿再让它自动更新到新版本，否则汉化会失效（重新运行本包即可）。

### 2. 运行安装脚本

双击 **`安装汉化.cmd`**。

脚本会自动从注册表 / 常见路径找到 r2modman 安装目录，然后：

1. 解析 `app.asar`；
2. 注入简体中文语言包，并把默认语言改成中文；
3. 重新打包并自检；
4. 把原 `app.asar` 改名为 `app.asar.zhcn-backup` 作为备份。

看到 `汉化安装成功！` 即完成。

### 3. 启动 r2modman

未手动选择过语言的用户会**直接看到简体中文**。

右下角活动栏最右侧的地球图标就是语言菜单，可在三种语言间切换：

```
en (English)
fr (Français)   WIP
zh (简体中文)
```

### 还原英文

双击 **`还原英文.cmd`**。会先校验备份的 SHA-256，确认无误后把备份改回
`app.asar` 并清理状态文件。

### 查看状态

双击 **`检查状态.cmd`**，只读检查，不修改任何文件。

## 三、命令行用法

`tools\r2modman-zhcn.ps1` 是实际干活的脚本，`.cmd` 只是带 `chcp 65001` 的包装器。

```powershell
# 安装（默认：界面中文 + 默认语言中文）
powershell -NoProfile -ExecutionPolicy Bypass -File tools\r2modman-zhcn.ps1 -Action Install

# 只汉化界面，不改默认语言（未选过语言的用户仍是英文）
... -Action Install -KeepDefaultEnglish

# 手动指定安装目录
... -Action Install -InstallDir "E:\Program Files\r2modman"

# 先看会做什么，不写任何文件
... -Action Install -DryRun

# 查看状态 / 还原
... -Action Status
... -Action Restore
```

| 参数 | 说明 |
| --- | --- |
| `-Action Install\|Restore\|Status` | 安装 / 还原 / 检查，默认 `Install` |
| `-InstallDir <路径>` | r2modman 安装目录，省略则自动查找 |
| `-LocaleFile <路径>` | 汉化数据文件，默认 `locale\zh-CN.json` |
| `-AppVersion <版本>` | 期望版本（默认 3.2.20），仅用于提示 |
| `-KeepDefaultEnglish` | 不改默认语言 |
| `-DryRun` | 演练，不写文件 |

退出码：`0` 成功，`2` 找不到安装/数据文件，`3` 进程在运行，`4` 还原前置条件不满足，
`5` 归档结构与预期不符，`6` 写出或自检失败。

## 四、原理

r2modman 是 Electron + Vue 3 应用，界面文案（vue-i18n 词条）**全部编译进**
`assets\*.js` 里，没有外挂语言包机制，因此汉化只能改写归档内容。

安装脚本对 `app.asar` 做 **三处等长或受控的改写**：

| # | 文件（3.2.20） | 改写 | 作用 |
| --- | --- | --- | --- |
| 1 | `assets/instance-BX-NcIvi.js` | 在末尾 `export` 前插入 `setLocaleMessage('zh', {...})` 与 `setDateTimeFormat('zh-CN', ...)` | 让语言菜单多出 `zh (简体中文)`，并注册中文日期格式 |
| 2 | `assets/index-K8wfC3Xn.js` | `availableLocales.includes(t)?t:"en"` → `…:"zh"`（等长） | `LocaleService` 的兜底语言改为中文 |
| 3 | `assets/ManagerSettings-DQRXhyVO.js` | `global:{… locale:"en"}` → `locale:"zh"`（等长） | 默认设置初始值改为中文；**从未手动选过语言的用户走的就是它** |

然后**整个归档重新打包**：按索引顺序连续排布所有条目、重算 `offset` 与
`integrity`（SHA-256，4 MiB 分块），未被改写的文件字节逐一原样搬运。
写完后脚本会用同一套解析逻辑**自检**（条目数、范围、被改写内容的哈希、汉化标记），
自检通过才替换正式文件。

### 为什么用「改名」而不是「复制」做备份

原 `app.asar` 有 190 MB。备份采用**同盘改名**（`app.asar` → `app.asar.zhcn-backup`），
瞬间完成且不多占空间；还原时再改回来。全流程磁盘开销只有新归档本身的 ~190 MB。

### 运行环境

只需要 Windows 自带的 Windows PowerShell 5.1（或 PowerShell 7），**不需要 Node.js**。
脚本本身以 UTF-8 with BOM 保存，避免 PowerShell 5.1 按 ANSI 代码页误读中文。

## 五、校验与已知限制

### 官方 3.2.20 参考值

| 项目 | 值 |
| --- | --- |
| 原始 `app.asar` 大小 | 190,509,184 字节 |
| 原始 `app.asar` SHA-256 | `7a4245ded37449a694a952b682fbd5b8085e2e4bcea294cdd5ddc5e782c96e83` |
| 归档条目数 | 7867 |
| 汉化后 `app.asar` 大小 | 190,542,280 字节（+33,096） |

安装脚本会在开始前打印读到的版本与条目数；与上表不符说明你的 r2modman 不是原始
3.2.20，脚本仍会尝试安装，但可能残留少量英文。

### 不会被翻译的内容

- **游戏名、Mod 名、作者名**：来自 Thunderstore 数据，属专有名词。
- **Mod 分类名**（如 `Items`、`Client Side`）：由 Thunderstore 提供，应用内也提示
  “分类由 Thunderstore 提供，无法翻译”。
- **README / CHANGELOG 正文**：Mod 作者自己写的 Markdown。
- **Electron 自带菜单**：应用设了 `autoHideMenuBar: true`，菜单默认隐藏。

### 自动更新会覆盖汉化

r2modman 升级时会用新版 `app.asar` 替换整个文件，汉化随之失效（备份也会变成旧版本）。
此时请**重新安装汉化包**；`还原英文.cmd` 会检测到这种“已更新但备份是旧版”的情况并
拒绝执行，避免把管理器降级。

### 与“Thunderstore Mod Manager”的关系

本包只针对 r2modman。同作者的 Thunderstore Mod Manager 结构类似但文件名不同，
未做适配。

## 六、文件清单

```
r2modman-zhcn-1.0.0-3.2.20/
├─ 安装汉化.cmd              安装
├─ 还原英文.cmd              还原
├─ 检查状态.cmd              只读检查
├─ 说明.md                   本文件
├─ locale/
│   └─ zh-CN.json            汉化数据（623 个条目 / 681 条字符串，可直接编辑）
└─ tools/
    └─ r2modman-zhcn.ps1     安装/还原/检查脚本
```

想改译文：编辑 `locale\zh-CN.json`，然后先 `还原英文.cmd` 再 `安装汉化.cmd` 即可生效。
JSON 里 `|` 是 vue-i18n 的复数分隔符，`{xxx}` 是变量占位符，请勿删除。
